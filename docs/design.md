# Borad 桌面版设计依据

Borad 的首要任务是让用户找到自己的请求、用量和额度；分享与自启动是次要、可逆的设备操作。首页先给出真实运行状态和三个数据入口，再放连接与启动偏好。顶部导航始终可见，让用户不必反复返回首页。

## 色彩与字体

默认暖纸主题沿用用户要求的 Claude 式暖色调；GitHub、Google 和森林主题可切换。森林主题参考 [Huegrove 的 Forest Dusk 色组](https://huegrove.com/palette/forest-dusk/)的深绿、鼠尾草绿与浅中性色关系，并针对屏幕文字调整：背景 `#f4f7f1`，面板 `#fcfefb`，正文 `#273d33`，次要文字 `#52675a`，操作色 `#2b5748`。正文和次要文字在背景上的对比度分别约为 10.8:1 和 5.6:1；操作色配白字约为 8.2:1。

中文界面正文使用本地打包的 [Noto Sans SC Variable](https://github.com/google/fonts/blob/main/ofl/notosanssc/METADATA.pb)，以保证简体中文界面的字形一致；拉丁文使用 DM Sans，标题使用 Noto Serif SC 和 Lora。字体均包含许可文件，运行时不从网络加载。

## 控件选择

- 首页使用带文字的完整卡片作为三个数据页的入口；图标分别代表活动、趋势与分层汇总，辅助识别而非替代文字。
- 状态区只呈现服务、Magpie 数据及公网连接的实际状态；不展示虚构的示例图表。
- 分享是主动开启的操作，地址、复制按钮和关闭操作相邻；关闭应用时明确结束分享。
- 自启动采用带明确文字和当前状态的开关，因为它是持续生效的二元设置。
- 左上角品牌与首页按钮都返回首页；顶部设置按钮进入口令和显示设置。图标按钮提供可访问名称和键盘焦点。
- 应用图标使用与界面一致的 `b` 字标和暖色底；不是数据状态，不随状态变化。

所有主题共享布局、字号和交互语义，并在配色、标题字体与圆角上体现各自风格。界面支持键盘焦点、窗口缩放和系统减少动画设置。
