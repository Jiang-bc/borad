# Borad 产品与界面原则

Borad 是查看本机 Magpie 请求、Token 用量和额度的工具。打开桌面程序时直接展示请求记录；顶部导航切换数据页，首页用于管理分享和启动设置。浏览器访问需要输入口令，包括公网分享和手动打开的本机地址。

## 信息与交互

- 优先呈现真实数据和可执行的操作；不用示意图、宣传口号或虚构指标填充空间。
- 桌面版只保留一组数据导航，顶部设置按钮带有文字；公网网页保留自己的导航。
- 数据范围、费用估算和来源说明可按需展开，不遮挡日常查看。
- 状态必须反映真实情况；分享地址、复制与开关放在一起，开机启动使用明确标识的开关。
- 口令保护公网访问；桌面窗口使用本机主进程签发的独立会话，不能用于公网域名。修改口令会使其他公网会话失效。
- 导航与功能位置在主题切换时保持稳定，按钮可键盘操作并显示焦点。

## 主题系统

主题不只是配色：字体、控件轮廓、面板边界和疏密共同形成视觉语言，同时保留相同的信息顺序与操作位置。

- **Claude：**暖中性色，衬线中文标题、柔和边界和宽松间距。
- **GitHub：**中性无衬线字体、紧凑分隔式卡片、清晰边框和较小圆角。
- **Google：**Roboto 与中文无衬线字体、圆角控件和较宽松的面板留白。
- **森林：**自然绿与中性色、衬线标题和不对称圆角，适度舒展。

字体在应用内打包，优先保证中文可读性，实际字体受字库覆盖范围与系统回退影响。主题切换立即应用到桌面和数据视图。字体及许可位于 `public/fonts` 与对应依赖中。

## 设计审核

每个可见控件应能明确表达用途并实际响应；每个信息区应帮助用户判断状态或完成任务。使用原生表单和折叠控件，保证标签、焦点、响应式布局与减少动画设置；在不同窗口宽度和每种主题下验证实际内容。
