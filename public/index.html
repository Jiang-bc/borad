统计口径与说明

Token 统一以 M 展示（1 M = 1,000,000 token），完整整数可在数值提示中查看。只统计本机网关历史日志，不包含尚未落盘的实时请求或仅在外部会话统计中出现的用量。总 Token = 已记录输入 + 已记录输出；字段缺失时会提示汇总不完整。缓存读取、写入单列，缓存与 reasoning 不额外加入总数。单条缺失用量显示「未记录」。

总消耗为 API 参考价估算，以美元（USD）展示，不代表真实支付或实际账单。免费（free）模型、免费及订阅调用也按对应标准付费 API 参考价估算；匹配型号、单价、缓存费用及具体算费由后端负责。未定价请求不按 $0 计入。

今天与近 7 天按北京时间（UTC+8）自然日计算，近 7 天含今天。历史曾用供应商仍可查看，不受当前停用状态影响；请求时间按当前设备时区显示。

额度口径与说明

同供应商、同语义窗口按账号汇总：同单位数量相加，同套餐百分比取平均。不同周期独立展示；余额总额已包含的分项不重复相加，窗口额度也不加入余额。未知值明确标为未知，查询失败保留历史值及源采集时间。额度页可见且未暂停时，每 60 秒向供应商采集，缓存每 3 秒同步；手动刷新立即排队采集，逐供应商显示进度。仅当所有有效窗口和余额均耗尽时隐藏供应商。
